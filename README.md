## commitsovercoffee.com

Sourav's personal website for lovers, haters and everyone in between, built with ❤️ and svelte.

## Usage 

Please note that this website was not created as a template. You are welcome to take inspiration from it, but I will not provide any guidance on using it. If you want a blog template, I recommend you check out [Astro themes](https://astro.build/themes/1/?search=&categories%5B%5D=blog&price%5B%5D=free).
